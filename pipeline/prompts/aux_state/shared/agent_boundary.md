# Agent boundary: aux-state query generation

## The agent writes (query-specific)

- `accelerators/{bench}/q{N}/layout.hpp`: partition payload structs and keying.
- `aux/module.{hpp,cpp}`, optional `aux/finalize.{hpp,cpp}`: `InterpretMutation` relevance and column watches, accumulators in `CreateTxnBuffer` + `AccumulateMutation`, `StageMaintenance` inputs and staged updates (a rebuild resyncs, never invalidate-only).
- Initial `CostModelParams` coefficients in `config/` JSON; `cost_model.hpp` (`AuxCostModelLocation`), passed to every engine's registration.
- Query-specific tests, benchmarks, calibration binaries.
- Registration from the query's own directory (`registration_checklist.md`): catalog entry, SQL entry point and bindings for the workload `engine_name` through the backend's registrars, append-only entries in shared eval helpers. No partial wiring, no second adapter tree.

## Fixed (never regenerated by query runs)

- `substrate/aux/`: `core/` (`AuxQueryModule`, `AuxEngineServices`, `AuxStateStore`, `aux_calibration.hpp`, `byte_stream.hpp`), `runtime/` (`RuntimeHost`, `AcceleratorRuntime`, `ColumnarBatch`, `wire`, `ThreadBudget`, `engine_slots.hpp`), `state/` (`VersionedAuxStore`, invalidation plans, partition keys), `maintenance/` (`MaintenanceAction`, `ActionCostEstimate`, `CostModelParams`, `SelectMinCostAction`).
- `accelerators/prims/`: generic COW structures; write access only through `primitive_publish` (`cow_primitives.md`). Engine-exact value semantics (numeric text, division, collation) come from the backend API role "value semantics".
- `backends/{engine}/**`: owned by the engine_backend pipeline and denied to query runs. Existing backends are few-shot only. A missing generic helper is a backend-addition request (`generated_layout.md`); work with what exists. Touch CMake only if targets are missing (auto-discovery normally covers test/bench/calibrate).

The runtime hosting the module is in-process or a shipped worker (profile `process_model`); the module is identical either way (typed `StateImage` payloads, no state encoding; only batches, arguments and result rows cross a process boundary, in `wire.hpp`). Related: `engine_interfaces.md`, `generated_layout.md`, `hard_guidelines.md`, `concurrency_contract.md`.
